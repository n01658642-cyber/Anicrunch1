Anilili · UI direction 02

Midnight Anime — restrained, cinematic, purple-first.

Same UX architecture, new visual primitives. The redesign removes most pill controls, nested surface cards and decorative icon boxes. Black carries the interface; purple only marks state, focus and primary action. Anime artwork gives contextual identity without turning the app into a themed novelty UI.

01 · Download

From generic form to media action

The download flow stays intact, but selection moves to underlines and flat radio rows. Storage becomes a data strip, not another card. The title area is contextual media instead of a generic dialog heading.

06 · System

The component rules

This is intentionally a smaller system than the first proposal: fewer primitive types, less decoration, and more meaning attached to each use of purple.

Color

Canvas is near-black. Purple is the sole brand accent. Green/red are semantic only. No pink secondary accent and no rainbow status palette.

Containers

Phone: 16px sheet radius. TV: one-sided accent edge. Internal groups are mostly flat and divided by rules rather than nested cards.

Selection

Tabs use an underline. List choices use a 2px violet rail. Focus adds a thin outline on TV. Selection never relies on glow alone.

Artwork

Contextual dialogs get a small anime thumbnail or backdrop crop. Artwork identifies the content; controls remain neutral and readable.

Typography

Show title hierarchy is stronger than control chrome. Uppercase micro-labels are reserved for context and section navigation.

Motion

No focus scaling. Use 120–160ms opacity, rail, underline and subtle background transitions. Purple glow appears only on focused/active edges.

Settings

No icon tile per row. No value pills. Use title, one-line description, value/switch and chevron. Section marker carries identity.

Danger

Destructive content stays neutral until action is explicit. Red appears on destructive labels/buttons and blocked states only.

TV target

Focusable rows remain ≥ 48dp. Current selection gets the rail; cursor focus gets outline. Back always dismisses unless work is in flight.

07 · Rollout

Implementation order

Keep the original rollout concept, but build the new primitives first so the product cannot drift back into card/pill variants.

01
Tokens + primitives: black/purple palette, divider, selection rail, underline tabs, focus outline, flat row and media header.
02
Download sheet: migrate resolution, save target, episode scope and storage into the new primitives.
03
My List + Continue Watching: replace status cards with the shared status row.
04
Confirmations + updates: use the restrained centered modal and editorial changelog.
05
Settings: remove group-card containers, icon tiles and value chips; preserve regrouping and one-line descriptions.
06
TV: adapt the same primitives for 48dp focus targets and D-pad traversal without scale animation.
